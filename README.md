# VEILCH

**Private by design. Fast by nature.**

VEILCH is a Windows desktop browser with a dark gaming-inspired interface, tabbed browsing, downloads, history, backgrounds, privacy controls, and a focused custom home page.

## Download

Windows builds are distributed through the repository's **Releases** section.

Official website: https://veilch.pages.dev

## Verify downloads

Before running an installer, compare its SHA-256 checksum with the checksum published for that release.

For VEILCH 3.5.1:

```
aef9d59d7c44eb384b60ce0df0e2beca9bad0f6ba1912e895a85098ba861769f
```

PowerShell:

```powershell
Get-FileHash .\VEILCH-Setup.exe -Algorithm SHA256
```

- Windows
- Microsoft Edge WebView2 Runtime
